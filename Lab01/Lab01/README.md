# Bài Lab 01 - Ứng dụng thông tin cá nhân

## 1. Mô tả bài toán
Xây dựng ứng dụng Windows Forms cho phép nhập thông tin cá nhân của sinh viên và hiển thị kết quả.

## 2. Kết quả đạt được
- Thiết kế giao diện đầy đủ control, bố cục rõ ràng.
- Xử lý các nút Hiển thị, Xóa, Thoát đúng yêu cầu.
- Bắt lỗi dữ liệu đầu vào.
